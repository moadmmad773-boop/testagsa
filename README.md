# شقتك اليومية — موقع حجز عبر المنصات

موقع عربي RTL جاهز للعمل على GitHub Pages.

## الفكرة
الموقع يعرض الشقة، الصور، المميزات، الموقع، واتساب، وزر "احجز الشقة الآن".
عند الضغط على الحجز تظهر نافذة فيها:
- Airbnb
- جاذر إن

ولا يوجد حجز مباشر داخل الموقع؛ المستخدم ينتقل إلى منصة الحجز التي تختارها.

## أهم ملف للتعديل
افتح `script.js` وعدّل الروابط داخل `CONFIG`:

```js
const CONFIG = {
  airbnb: "رابط إعلانك في Airbnb",
  gathern: "رابط إعلانك في جاذر إن",
  googleMaps: "رابط موقع الشقة في خرائط Google",
  whatsapp: "https://wa.me/9665XXXXXXXX"
};
```

## الصور
ضع صور شقتك داخل مجلد `images`.
يمكن لاحقًا تحويل مربعات الصور التجريبية في `index.html` إلى صور فعلية.

## رفعه على GitHub Pages
1. أنشئ Repository جديد في GitHub.
2. ارفع الملفات والمجلدات كما هي.
3. من Settings > Pages اختر النشر من فرع `main`.
4. سيظهر الموقع كرابط GitHub Pages.

GitHub Pages يستضيف المواقع الثابتة مباشرة من مستودع GitHub، لذلك لا تحتاج استضافة منفصلة لهذا الموقع.
