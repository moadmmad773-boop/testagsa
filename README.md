# شقتك اليومية

صفحة هبوط عربية متجاوبة لحجز شقة يومية، محسّنة بتصميم RTL، شعار محلي، وأيقونات SVG حقيقية بدون مكتبات إضافية.

## التخصيص السريع

1. افتح `script.js` وعدّل روابط Airbnb وجاذر إن وخرائط Google ورقم واتساب داخل `CONFIG`.
2. استبدل مربعات المعاينة بصورك الحقيقية من قسم الصور في `index.html` أو أضف صورك إلى مجلد `images`.
3. شغّل الموقع عبر أي خادم ملفات ثابت، مثل:

```bash
python3 -m http.server 8080
```

الأيقونات مضمّنة داخل `index.html`، لذلك لا تحتاج إلى تحميل مكتبة أيقونات خارجية.

## الملفات الرئيسية

- `index.html` — هيكل الصفحة وشعار SVG ومجموعة الأيقونات.
- `style.css` — التصميم المتجاوب والألوان والتفاعلات البصرية.
- `script.js` — روابط الحجز، واتساب، الخرائط ونافذة المنصات.
- `images/design-reference.png` — المرجع البصري المرفق.
